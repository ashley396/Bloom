# Bloom X v10.0 — Massive Website & Assistant Update

Built from the stable Bloom v9.1 integrated workflow.

## Major upgrades
- Completely redesigned Website Studio X.
- Replaced clip-art website tiles with real floral photography placeholders.
- Added Hydrangea, Romance, Sympathy, and Wedding photo filters.
- Added upload-your-own arrangement photo preview.
- Added a much richer desktop/mobile storefront preview.
- Added featured products, occasion links, florist story, local delivery, and contact sections.
- Introduced Lily, Bloom's creative florist assistant.
- Introduced Rose, Bloom's business manager assistant.
- Added one-click Lily and Rose prompt buttons on the dashboard.
- Added a more polished, responsive commercial interface.

## Important
The included stock photographs are remote Pexels placeholders and require internet access. Replace them with photos of arrangements the florist can actually create before publishing products for sale.

## Database
No new Supabase migration is required for this update.

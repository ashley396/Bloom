# Bloom X v13.0 — Pastel POS Edition

## Complete visual redesign
- Bright pastel pink, cream, sage, peach, and lavender palette.
- Light floral sidebar, clean header, rounded panels, softer shadows, and polished spacing.
- Dashboard redesigned to feel like a professional florist point-of-sale command center.
- Product and Floral Library cards now resemble visual product pads.
- Order Builder restyled as a commercial POS checkout workspace.
- Responsive desktop, tablet, and phone improvements.

## One Branding Center
- Settings is now the only place to upload the shop logo.
- The saved logo continues to feed the top-left brand, website, invoices, receipts, manifests, and printed materials.
- Website Studio no longer asks for a second logo upload; it uses the saved branding logo automatically.

## Existing functionality preserved
- Orders, customers, inventory, recipes, invoices, payments, deliveries, expenses, reports, Website Studio, Lily, Rose, and voice settings remain included.
- No new Supabase migration is required for v13.0.

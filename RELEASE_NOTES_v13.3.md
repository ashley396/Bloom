# Bloom X v13.3 — Working Pastel POS

- Removed preset prices from the front product tiles. Clicking a tile opens the order builder with the price field ready for the florist.
- Added an editable Product Tile Manager. Florists can add, edit, delete, and reorder tiles, upload tile pictures, and choose whether a text label appears.
- Picture-only tiles are supported when the image already clearly identifies the product.
- Replaced the duplicate/non-working clock controls with one working Clock In / Clock Out button.
- Prevented duplicate Hear Rose controls.
- Replaced the “all pages match” Lily message with an encouraging shop message.
- Preserved the approved pastel Bloom design across the application.

No Supabase migration is required.

# Bloom X v11.2 — Connected Workflow

- Orders now save the selected product and automatically deduct matching recipe ingredients from inventory.
- Low or missing recipe ingredients return a clear inventory warning without blocking the order.
- Products now include Duplicate and Publish/Remove from Website controls.
- Published status is visible on every product card.
- Website preview refreshes after publishing a product.
- Existing Floral Library, invoice, payment, inventory scanning, Lily, and Rose features are preserved.

No new migration is required when the existing v6.0 schema has already been installed.

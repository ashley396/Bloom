# Bloom v19.0 — Florist Advantage

## Included in this release

### Morning Dashboard upgrades
- Added today's pickup count alongside orders, deliveries, low stock, and outstanding balances.
- Added average-order value to the morning command bar.
- Added one-click shortcuts for a new order, new customer, payment collection, delivery schedule, and inventory receiving.

### Customer 360 Timeline
- Added a new **View timeline** action to every customer card.
- Added lifetime value, order count, average order, and outstanding balance summaries.
- Added recent order history with payment status.
- Added customer favorites, important dates, repeat recipients, occasions, and notes.
- Customer matching uses the saved phone number first and customer name as a fallback, so no database migration is required.

### Production packaging
- Application version updated to 19.0.0.
- Added the `customer-insights` protected Netlify function.
- JavaScript syntax validation passes for all 42 JavaScript files.

## Scope note
This is the first completed v19 milestone. The existing Floral Library, recipe builder, profit intelligence, inventory freshness, and Lily entry points remain intact. A larger visual-library expansion and advanced product profitability ranking are appropriate for a later v19.x release after this package is deployed and tested.

# Bloom v23 — Lily AI Studio

## What is new

- Added a dedicated **Lily AI Studio** with conversational prompts, quick actions, progress steps, and saved local drafts.
- Lily can prepare structured website copy, product listings, marketing copy, SEO text, and image concepts in one request.
- Added an approval preview so AI work is never saved or published automatically.
- Approved website copy can be applied directly to Website Studio; product drafts open in the Product Builder for review.
- Added optional Lily speech with a warm, bubbly voice profile and a clear voice on/off control.
- Added an original temporary shop-dog animation with a whole-body wiggle and paw-tap interaction. This placeholder can be replaced with custom Lily artwork after reference photos are supplied.
- Added responsive styling and reduced-motion support.

## Deployment

No Supabase migration is required. Replace the matching files, commit, and push the development branch once.

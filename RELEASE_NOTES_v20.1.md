# Bloom v20.1 — Atelier Edition

This release is an appearance-only refinement of Bloom v20. No workflows, business logic, database structures, API functions, payment behavior, or feature capabilities were changed.

## Visual improvements

- Introduced a complete Bloom Atelier design system with unified color, spacing, typography, depth, radii, and interaction tokens.
- Refined every page to share the same visual rhythm and hierarchy.
- Rebuilt the desktop navigation appearance with consistent iconography, section hierarchy, active states, and softer motion.
- Upgraded the header, shop switcher, branding, cards, buttons, forms, tables, dialogs, status badges, and empty surfaces.
- Improved the Point of Sale dashboard hierarchy without changing its layout or actions.
- Polished BloomShot Studio, Website Studio, Products, Orders, Reports, Payments, and supporting pages to feel like one product.
- Added refined responsive behavior and reduced-motion accessibility support.
- Preserved the existing floral personality with a more elegant plum, berry, blush, sage, cream, and warm-white palette.

## Cost

The redesign uses only HTML and CSS already served with Bloom. It adds no paid service, design-library subscription, image API, or recurring operating expense.

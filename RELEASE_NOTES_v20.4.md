# Bloom v20.4 — Signature UI

Appearance-only release based on the approved clean floral SaaS mockup.

- Removed all decorative dashboard shapes that could cover totals or controls.
- Rebuilt dashboard spacing and hierarchy for a cleaner professional presentation.
- Reduced Edit Tiles to a compact toolbar control.
- Removed the Live Activity developer panel from Orders.
- Added Starter ($39), Pro ($79), and Premium ($129) selections.
- Added a 14-day free trial to every plan.
- Added plan and trial metadata to signup without changing operational features.
- Improved desktop, tablet, and mobile layouts using one shared design system.

No Supabase migration is required.

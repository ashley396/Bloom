# Bloom v8.5.3 Restore Release

This release restores the full Bloom Flagship interface from the last known working commit before the simplified replacement project.

Restored:
- Full sidebar navigation
- Website Studio
- Customer edit and delete
- Products and recipes
- Floral library
- Deliveries
- Reports
- Staff
- Marketplace
- Multiple stores
- Payments and other existing modules
- Working order user_id fix

The tax-percent and delivery-mileage changes from v8.5.1/v8.5.2 are intentionally not included in this emergency restore, because those packages replaced the full interface. They should be merged additively in a later tested release.

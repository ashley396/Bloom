# Bloom v20.2 Professional Edition

This release is an appearance-only redesign. Existing Bloom functions, Supabase logic, Stripe logic, Lily/Rose behavior, orders, products, inventory, reports, and Netlify functions remain unchanged.

## What changed
- Removed the oversized decorative bubble and all visual overlays that could cover content.
- Rebuilt the desktop layout around a calm 224px navigation rail and a consistent page grid.
- Reworked the POS dashboard hierarchy so the welcome, metrics, product pads, current order, progress, and payment areas do not overlap.
- Standardized cards, headings, controls, buttons, forms, tables, page spacing, shadows, and borders across all pages.
- Added a purpose-designed mobile layout with a floating five-item bottom navigation.
- Added a new original Bloom app icon, favicon, Apple touch icon, and PWA manifest.
- Added responsive rules for tablets and phones without changing functions.

## Design references
The layout strategy borrows general workflow principles—not artwork or exact layouts—from florist platforms that emphasize fast order entry, visual catalogs, recipe-based work, delivery coordination, and unified business dashboards.

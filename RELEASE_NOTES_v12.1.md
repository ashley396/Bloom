# Bloom X v12.1 — Rose Voice Edition

- Moved Rose to the top of the dashboard beside the welcome area.
- Removed Rose's visible speech bubble and long written briefing.
- Rose's daily briefing is still generated privately and spoken when **Hear Rose** is pressed.
- Added a Rose voice selector in Settings using the female voices installed on the device.
- Added adjustable voice speed and warmth controls.
- Improved female voice matching so Bloom avoids male/default voices whenever a female English voice is available.
- No Supabase migration is required for this release.

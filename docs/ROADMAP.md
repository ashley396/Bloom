# Bloom Thanksgiving Scope

## Included in the current foundation

- Secure setup and login
- Dashboard
- Customers
- Orders
- Inventory
- Bloom Market Early Access supplier directory

## Required before a public Thanksgiving release

- PostgreSQL persistence and migrations
- Employee invitations and granular permissions
- Customer recipients and reusable addresses
- Full order line items, taxes, discounts, and status timeline
- Payment processor integration
- Receipts and POS register workflows
- Delivery routes and driver workflows
- Purchase orders and receiving
- Audit logs, backups, monitoring, and rate limiting
- Legal policies and production security review

# Bloom X v13.1 — True Pastel POS Redesign

This release rebuilds the live dashboard/POS interface to match the approved pastel florist mockup instead of merely changing colors.

- New two-column florist POS workspace
- Pastel product pads with floral imagery
- Rose and Lily top assistant cards
- Right-side progress and payment panels
- Current-order workspace styled like a commercial POS
- Light floral sidebar and polished responsive layout
- Existing data, APIs, invoices, inventory, orders, and Settings branding remain intact
- One shared logo upload remains in Settings → Branding

No Supabase migration is required.
